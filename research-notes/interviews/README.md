# Customer discovery interviews

One file per conversation, copied from
[`../customer-discovery-template.md`](../customer-discovery-template.md).

Naming: `YYYY-MM-DD-<business-type>.md`, e.g. `2026-11-04-co-packer.md`.
Anonymise the business name if you do not have permission to record it.

`tools/verify.sh` counts the files here (excluding this README and the template)
and reports Phase 0 progress against the five-conversation milestone. That count
is the only "proof" Phase 0 can have -- the evidence for a conversation is the
notes you actually wrote down, and this directory is where the repo looks for
them.
